# 电商用户行为数据分析与流失预警看板

基于淘宝公开用户行为数据集（清洗后约296万条）的完整数据分析项目。

**核心指标**：复购率54.8% | 次日留存率77.3%（数据治理修正后） | 流失预警名单召回效率提升1.35倍

**内容**：
- 数据质量核查与清洗（时间戳异常处理，清洗前后留存率差57个百分点）
- 漏斗分析、Cohort留存分析、用户分层
- 流失预警模型（随机森林 vs XGBoost对比，AUC与lift评估）
- Streamlit交互式看板（本仓库）

**技术栈**：Python（pandas/sklearn/matplotlib）、Streamlit
